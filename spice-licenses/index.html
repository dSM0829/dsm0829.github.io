Built with Android NDK 27.1.12297006 (clang), API 24, 16 KB page alignment, then llvm-strip --strip-unneeded.

Replacing the library / 바꿔 끼우는 차례

  1. Download ngspice-47.tar.gz, unpack it to src/ngspice-47 next to the four build files above, and change the files in src/frontend/numparam/ as you like.
    ngspice-47.tar.gz 를 받아 위 빌드 파일 넷 옆의 src/ngspice-47 에 풀고 src/frontend/numparam/ 의 파일을 고칩니다.
  2. Run bash build_android.sh arm64-v8a (or x86_64). Step 3 of the script compiles numparam alone and links it: clang -shared -o libngnumparam.so spicenum.o xpressn.o mystring.o -Wl,-soname,libngnumparam.so -Wl,-z,max-page-size=16384 -lm. The script expects the NDK under ~/Library/Android/sdk/ndk/ on macOS; change the NDK and TC lines for another machine.
    bash build_android.sh arm64-v8a(또는 x86_64)를 돌립니다. 스크립트 3단계가 numparam 만 컴파일해 위 명령으로 링크합니다. NDK 자리는 맥 기준이니 다른 기계에서는 NDK · TC 줄을 바꿉니다.
  3. In the APK, replace lib/<ABI>/libngnumparam.so with your file (keep the file name), then align (zipalign) and sign the APK again with your own key and install it.
    APK 안의 lib/<ABI>/libngnumparam.so 를 그 파일로 바꾸고(파일 이름은 그대로) zipalign 뒤 자기 키로 다시 서명해 설치합니다.

The engine keeps working as long as your library exports the same 15 functions the engine calls (nupa_* and the others your build of step 2 exports) and uses only the 43 engine symbols listed in exports_numparam_bridge.txt. The app opens libngspice.so first, in one dlopen, and Android loads libngnumparam.so with it as its dependency; do not load libngnumparam.so on its own first.

엔진이 부르는 함수 15개(nupa_* 등 — 2단계에서 만든 파일이 내보내는 것)를 그대로 내보내고, 본체에서는 exports_numparam_bridge.txt 의 43개만 쓰면 엔진은 그대로 돕니다. 앱은 libngspice.so 를 먼저 한 번의 dlopen 으로 열고 안드로이드가 libngnumparam.so 를 딸린 것으로 함께 올립니다. libngnumparam.so 를 먼저 따로 열면 안 됩니다.
