MPP Viewer: MPXJ source code and relinking

MPP Viewer (Android, com.vismstudio.mpp) reads schedule files with the MPXJ library, Copyright Packwood Software and contributors, licensed under the GNU Lesser General Public License, version 2.1 or (at your option) any later version. This page gives you the library source, our change to it, and a way to replace the library inside the app with your own build, as section 6 of the license provides.

App version 1.0.0 uses MPXJ 16.11.0 with one modification (called mpxj-16.11.0-fk1, made 2026-11-15).

Files

  • LGPL-2.1.txt: the license text.
  • mpxj-16.11.0-sources.jar: the unmodified MPXJ 16.11.0 source, as published on Maven Central.
  • mpxj-16.11.0-fk1.patch: our modification. One method in org/mpxj/common/UnmarshalHelper.java: on Android the XML reader is created from the bundled Xerces parser when it is present, because the platform parser rejects a feature that MPXJ sets.
  • mpxj-16.11.0-fk1.jar: the modified library as shipped in the app.
  • make-patched-jar.sh: builds that jar from the unmodified jar, the source jar and the patch.
  • relink.sh: replaces MPXJ inside an MPP Viewer APK with your jar and signs the result with your key.

Build the modified library

./make-patched-jar.sh mpxj-16.11.0.jar mpxj-16.11.0-sources.jar mpxj-16.11.0-fk1.patch my-mpxj.jar

Needs a JDK 17 or later. Get mpxj-16.11.0.jar from Maven Central (net.sf.mpxj:mpxj:16.11.0). To compile the patched class, pass the two jars it refers to: CP=xercesImpl-2.12.2.jar:jakarta.xml.bind-api-3.0.1.jar.

Relink the app with your library

./relink.sh MPPViewer.apk my-mpxj.jar my-keystore.jks my-alias MPPViewer-relinked.apk

Needs Java 17 or later, apktool 2.9 or later, zip/unzip and the Android SDK build-tools (d8, zipalign, apksigner). The app ships the org.mpxj classes unshrunk and with their original names, and the libraries MPXJ calls (Apache POI, RTF Parser Kit and the others listed on the licenses page) keep their original class names too, so your build only has to keep the public API that the app calls. The script replaces only the code; resources and native libraries stay as they are. Get the APK from your own device (for example adb shell pm path com.vismstudio.mpp, then adb pull; if the app is installed as split APKs, relink the base APK and install it together with the other splits re-signed by the same key).

The relinked APK is signed with your key, not ours. Android will not install it over the store version: uninstall that first. Copies kept in the app's library are removed with it; your original files are not touched. Purchases made through Google Play are not recognised by an APK that Google Play did not deliver.
